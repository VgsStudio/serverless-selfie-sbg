Privacidade em 4 linhas
  • Sem cadastro nem login: o site cria uma sessão anônima só neste navegador.
  • Você é responsável pela imagem que envia: use uma foto sua ou que tenha direito de usar. É um projeto educativo e de demonstração.
  • A foto serve apenas para gerar a moldura. Nada de reconhecimento facial, galeria pública ou exibição no telão.
  • Foto e molduras são apagadas automaticamente em até 1 hora. Dá para excluir antes, a qualquer momento.
  • Prefere não usar o rosto? A imagem de exemplo funciona igualzinho.

Enquadre

Arraste a foto para ajustar o que aparece na moldura.

Ao gerar a moldura, você declara que tem o direito de usar esta imagem (de preferência, uma foto sua) e se responsabiliza pelo conteúdo enviado. Este é um projeto educativo e de demonstração da palestra. A foto e as molduras são apagadas automaticamente em até 1 hora.

Acompanhe sua selfie na nuvem

  1. API cria o trabalho e autoriza o envio
  2. S3 recebe o arquivo direto do seu celular
  3. EventBridge avisa que um arquivo chegou
  4. Step Functions + Lambda geram as molduras
  5. Pronto! a API libera o download
